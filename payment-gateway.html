Payment Gateway

Reusable gateway engine for deposit, payout, status API and callbacks.

How it works

Create one gateway, configure DEPOSIT / WITHDRAW / STATUS requests, then add channels. Templates support variables such as ${credential.token}, ${member.id}, ${referenceId}, ${amount}, ${channel.providerCode}, ${callbackUrl}, ${credential.basicAuth}, ${epochMillis} and custom channel variables.
