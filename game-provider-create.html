6. Signature

Hash type, case, formula builder, and ukey rules.

Use provider document formula here. Example: ${method}${operator_id}${account_id}${ukey}${secret_key}
Image templates: ${game_code}, ${game_name}, ${provider_code}, ${provider_name}, ${category}, ${key}, and row fields such as ${gameID}
Player round: ${provider_player_id}, ${datePlayed}, ${hour}, ${timeZone}, ${session_start_date_time}, ${session_end_date_time}
Built-in: ${operator_id}, ${secret_key}, ${account_id}, ${username}, ${member_id}, ${ukey}, ${method}, ${amount}, ${amountNumber}, ${amountCents}, ${transaction_id}, ${game_code}, ${currency}, ${request_date_time}, ${timestamp}, ${TIMESTAMP_SECONDS}, ${TIMESTAMP_MILLISECONDS}, ${NONCE_32}, ${SESSION_ID}, ${UUID}, ${REQUEST_ID}, ${ISO8601_NOW}, ${RAW_JSON}, ${signature}
Signature types: MD5, SHA1, SHA256, HMAC_SHA256, HMAC_SHA1, HMAC_SHA256_BASE64, HMAC_SHA1_BASE64
Crypto: ${md5:...}, ${sha1:...}, ${sha256:...}, ${aes128ecb_base64:${rawJson}:${AgentKey}}. Dynamic date values support DATETIME_FORMAT(zone|pattern), e.g. DATETIME_FORMAT(-04:00|yyMMd)
Nested map game list: use Game Code Path @key and Category Path @group
Typed JSON: use ${amountNumber} / ${amount_number} / ${AMOUNT_NUMBER} as the complete value to send a JSON number while existing ${amount} remains a string. Use ${amountCents} / ${amount_cents} / ${AMOUNT_CENTS} to multiply by 100 and send an integer smallest-unit value (RM 10.50 �?1050). Use ${UUID} for an RFC 4122 UUID such as provider plat_sn.
Custom: any key added in Dynamic Provider Variables, example ${merchant_id}, ${nonce}, ${token}
